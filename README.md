🎬 <b>IMDB Sentiment Analysis </b>

«An NLP project that uses a pre-trained Transformer model to analyze IMDB movie reviews and classify their sentiment as Positive or Negative.»

📌 <b> Description </b>

This project demonstrates how Natural Language Processing (NLP) and Transformer-based Deep Learning models can be used to understand the sentiment of movie reviews.

A user provides a movie review as text, and the model processes the review through tokenization and Transformer-based classification to produce sentiment probabilities and a final Positive or Negative prediction.

The project also includes an interactive Gradio interface, allowing users to enter their own movie reviews and test the model easily.
